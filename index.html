Mentions et confidentialité

CLIC — Commencez simplement.

CLIC est une application web de productivité personnelle. Aucune donnée n'est envoyée sur un serveur : tâches, sessions, statistiques et préférences sont enregistrées uniquement dans le stockage local de votre navigateur (localStorage).

Vous pouvez supprimer toutes vos données à tout moment via « Réinitialiser mes données » dans les réglages, ou en vidant les données du site de votre navigateur.

Le bouton CLIC affiché à l'écran est une commande logicielle. Un boîtier physique Bluetooth pourra être connecté dans une version ultérieure ; il n'est pas encore disponible.

CLIC ne bloque pas d'autres applications : un site web ne le peut pas. L'anti-distraction se limite à une détection honnête et à une mise en pause de la session.
